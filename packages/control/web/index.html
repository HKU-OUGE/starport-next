复用说明

自动复用只检查当前登录账号的 Conda 登记表和常见安装目录，不遍历共享盘或其他用户目录。找到的环境自动登记；Python 兼容性需另行验证。

选定目录在服务器本地发布为固定快照，再以只读方式挂入任务。优先使用写时复制；不支持时复制文件。不会重新安装依赖。停用不删除快照、不打断已提交任务。

Python／Conda 环境可能依赖外部动态库或绝对路径，发布成功不代表能够运行。目录外软链接、特殊文件和部分凭据文件会被拒绝。只读不隐藏内容，固定任务路径也无法抹去文件内部的原始路径。请先检查目录内容；不要选择整个 HOME 或系统目录。

Claude 通过 compute_resources 查看版本，再用 compute_submit 的 mounts 选择。数据位于 /datasets/<ID>，环境位于 /dependencies/<ID>。目录仅在所属服务器的任务内可见；多个项目可读取已发布内容。

连接设置说明

填写已创建的 Cloudflare Access 自托管应用。域名需已有 DNS 与 Tunnel 路由，邮箱名单需同时配置在 Cloudflare 的允许策略中。团队地址和 Audience 从 Zero Trust 应用页面取得。

本机运行 Tunnel 时需安装 cloudflared 并填写对应 Token；已有外部连接器时可不勾选。Token 不回显、不进入工作区或配置导出。

保存只应用本机配置，不创建云端资源。源站检查只确认无凭据请求被拒绝；公网登录需另行验证。详见 docs/REMOTE-ACCESS.md。
