使用指引

Windows 管理配置和项目文件。工作区只获得自己的文件、受控出口和计算接口。上传、下载均校验 SHA-256；删除仅支持文件和空文件夹。

项目内通过 STARPORT_COMPUTE_URL 和 STARPORT_COMPUTE_TOKEN 调用 /health、/jobs、任务日志、取消和产物下载。真实服务器地址与凭据由控制端保管。

当前版本提供管理和文件面板。WSLg 原生窗口、完整会话界面及 Windows 实机验收仍独立进行。
