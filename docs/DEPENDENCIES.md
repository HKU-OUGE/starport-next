# 依赖与数据复用

本机管理面板的「依赖与数据」页支持逐服务器登记 Python／Conda 环境，以及数据集／
模型权重目录。目录在服务器本地发布为独立固定快照，任务按 ID 和 SHA-256 版本选择，
不重新安装依赖。优先 FICLONE 写时复制，文件系统不支持时复制文件；因此并非所有服务器
都能零额外空间复用。原目录后续修改不影响已发布版本。

双服务器的空目录、MCP 与面板验收见 [验证记录](verification/dependency-reuse.json)。
当前没有现成 Conda 环境，未将空目录测试当作真实解释器／import 验收。

## 自动复用 Conda

点击「自动复用 Conda」会识别当前服务器登录账号的 `~/.conda/environments.txt`、
用户目录下 Miniconda／Anaconda／Miniforge／Mamba 的常见安装位置，以及 `/opt/conda`
等默认前缀。它不遍历共享盘或其他用户目录，也不在宿主执行 Conda／Python 环境里的代码。
已在发布或可用的同一来源不重复登记；没有发现环境时可手动填写具体目录。
Conda 根目录中的 `pkgs` 缓存和 `envs` 子环境不纳入该版本，各环境分别登记。
自动登记仍受敏感文件、外部链接与容量检查约束，发布成功仍需独立 import 验证。

## 登记与使用

1. 在面板选择服务器，点击「新建复用」，填写名称、类型与具体绝对目录。
2. 检查目录中的配置、凭据、日志和内容，确认可向任务公开。不要选择整个 HOME、共享卷
   或系统根目录。已发布内容对本安装的所有项目可读，不提供逐项目数据 ACL。
3. 点击「发布只读版本」。后台复制与校验完成后显示「可用」、版本和大小；关闭网页不
   中断发布。失败只返回错误码；来源路径和发布进程信息留在管理端。结果不明时刷新并
   按登记 ID 核对，不重复提交。中断发布标记失败，残留内容保持私有且不可选。
4. Claude 调用 `compute_resources` 选择同一服务器，再把 `id`、完整 `version` 传入
   `compute_submit.mounts`。面板「复制引用」可复制 node 与 mounts。环境挂到
   `/dependencies/<ID>`，数据挂到 `/datasets/<ID>`，固定只读且不传宿主路径。
5. 选择 Python 解释器时另设 `python_environment: "ID"`。先用小任务验证解释器和
   import，再运行实际任务。缓存、新包和结果放入任务可写目录，不原地修改共享版本。

「停用」阻止新任务选取该版本；已经提交的任务继续使用原版本，结束时自动释放挂载。
停用不删除原目录或快照。自动回收与发布取消尚未实现；不要手动删除仍被任务引用的资源。
快照不进入配置导出，迁移设备／服务器后需重新登记和验证。

## 系统 Python、venv 与 Conda

Linux 可以只读绑定指定目录，但 Python 环境未必只依赖那一个目录。系统 Python 常依赖
标准库、动态加载器和系统库，不能为了兼容而挂入整套宿主系统。用户 Conda 环境通常更
集中，但脚本 shebang、`.pth`、二进制 RPATH 和元数据可能固定原安装路径。普通 venv
可能只链接到宿主 Python，不保证可搬移。见 [Python venv](https://docs.python.org/3/library/venv.html)
与 [Conda Pack](https://conda.github.io/conda-pack/)。

本实现发布快照后挂载，不直接跟随持续变化的宿主目录，也不自动运行 activate、
conda-unpack 或任意修复脚本。内部绝对软链接转成快照内相对链接；目录外、悬空、循环
软链接和特殊文件拒绝发布。Python 行始终标记「兼容性未验证」；目录可用不等于环境可
运行。需要时由操作员准备经修复的中性路径环境或 wheel／模型缓存，再发布新版本；不得
用宿主管理 Shell 执行模型任务来绕过兼容问题。

## 路径与边界

只读防止任务修改资源，不隐藏内容。软链接会暴露目标，固定挂载别名也不能消除包内
绝对路径、调试符号和配置。发布时统计含完整源目录字符串的文件并在面板提示；这是
字节匹配辅助检查，不是凭据扫描、身份匿名性证明或全面脱敏。`.ssh`、`.aws`、`.git`、
`.netrc`、`.condarc`、`pip.conf` 等已知敏感条目拒绝发布，仍须人工检查其他配置和数据。

执行器只接受已发布 ID／摘要，拒绝任意 source、destination 和写挂载。管理操作只在
本机面板提供，需会话、Origin 和 CSRF；项目 MCP 只有发现与选取权限。主机路径、管理
SSH 和发布进程不进入 MCP。实际运行时还应验证写入失败、外部目录不可见及 mountinfo
不泄漏来源；不能仅凭 OCI 配置声称边界有效。

默认每次发布最多 100,000 个条目、4 TiB 内容，超过限制拒绝；可信 worker 配置可调整
`resource_max_entries`／`resource_max_bytes`。发布需要本机空间和 I/O，写时复制仍需读取
内容计算摘要。不同服务器独立登记资源；软链接不会跨机器共享文件。
