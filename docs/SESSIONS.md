# 网页会话

从左侧「会话」新建项目会话，直接输入消息。列表、消息、工具调用与结果、累计费用估算、停止、重命名、归档／恢复均由 Next 独立管理；「Claude 工具」继续保留网页项目桌面与本机 WSLg。

## 执行与认证

网页会话复用控制端配置的 API 模型和网关。API Key 留在 Windows 控制端；Agent SDK 在经过验证的 WSL2 项目边界内运行，工作目录为 `/workspace`，通过项目计算 MCP 使用已接入的服务器。会话无需解锁图形密钥环，也无需 Claude 官方订阅账号登录。

这是 API 会话，不接管原生 CLI／Desktop 的账号会话或历史。原生账号登录、真实对话和工具调用仍须分别验收。当前启用项目文件工具、Bash、计算 MCP、官方 SDK WebSearch 和网页读取 MCP；工具卡片用于查看执行内容，尚未提供逐工具审批或原生会话同步。

界面标记为「SDK 累计估算」的费用使用 SDK 的会话累计估算，续接后的数值已包含以前轮次，不能把各次结果相加；实际账单以 API 提供方为准。依据 [SDK 费用统计](https://code.claude.com/docs/en/agent-sdk/cost-tracking)。

网页读取 MCP 会额外调用一次同模型 Messages API，其 usage 在工具结果中返回，不包含在 SDK 累计估算里；搜索与网页读取按 API 提供方实际用量计费。

新会话绑定创建时的项目和配置模型，浏览器不能指定 SDK resume ID、执行路径或宿主命令。每个项目同时只有一个 SDK／命令写入者；不同项目可独立执行。这个工作区互斥不改变远端计算任务的并发配置。无美元预算上限；现有每轮最多 8 次 SDK turn、300 秒控制端超时仍适用。消息最长 65,536 字符且 JSON 编码不超过 120,000 字节。

## 附件与联网

把文件拖入会话区域，或点击「＋ 附件」选择多个文件；截图可直接粘贴到消息框。上传完成后输入要求并发送，也可以只发送附件。每条消息最多 8 个文件，单文件 64 MiB、合计 128 MiB；文件夹和更大文件使用「打开项目文件夹」。移除附件只取消本条消息的引用，不删除已上传的项目文件。

文件按会话和上传请求 ID 保存到项目 `.starport-attachments/`，同名文件不覆盖。上传验证 SHA-256；断线后重试沿用同一上传 ID。文件名及内容不做简繁转换。待发附件在当前标签页刷新后保留，已发送的附件在历史消息中显示；切换会话不会改变正在上传批次的目的项目。上传失败时可重试或移除，刷新后丢失本地 File 对象的未完成项需要移除后重新选择。最多保存 1,024 个上传条目／会话。

Claude 通过项目 Read 工具读取文字、图片与支持的 PDF；表格、压缩包等按项目工具和已安装依赖处理，上传成功不保证所有格式都能直接解读。只上传用户选中的文件，不暴露 Windows 文件路径或挂载主机目录。网页附件采用浏览器 File API，与 WSLg 跨系统原生拖放是不同通道。

可直接要求「搜索某个主题并列出来源」，或「读取这个网页并总结」。搜索使用官方 Agent SDK 的 `WebSearch`。读取使用 `mcp__starport-web__web_fetch`，调用 Anthropic [服务端 Web Fetch](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool)，经现有模型网关和所选代理连接 API；项目和控制端均不直接访问传入 URL，不扩大 CONNECT 域名允许列表。无需另配搜索 Key。

网页读取只接受公开 HTTPS 域名 URL（最长 250 字符），拒绝用户凭据、IP、私有域名和非标准端口；Anthropic 继续检查目标、重定向及组织策略。网页和 PDF 可读取，不提供登录网站、交互浏览器或任意文件下载。结果包含来源、读取时间和额外 API usage；网页不可访问、服务未授权或提供方拒绝会显示工具错误，不回退到宿主网络。网页内容和附件均作为不可信数据，来源链接按安全链接显示，原始 HTML 不执行。

## 持久性与停止

控制端的私有 `sessions/` 保存会话索引与显示事件；完整 SDK 上下文保存在项目持久 HOME 的独立 SDK 配置目录。原始 SDK 事件仍留在项目 `.starport-events/`，简繁转换不改写代码、路径和原始记录。显示内容按 SDK 完整消息块追加，不是逐 token 动画。

刷新、关闭或重新打开网页只读取历史，不重新执行消息。发送具有请求 ID；相同 ID、消息和附件返回原来的轮次，不同内容复用同一 ID 会被拒绝。网络结果不明时保留原请求重试，不能换 ID 自动重发。控制端重启会保留已完成上下文，未结束的轮次标为中断；重新验证边界后，用户可以明确继续。

「停止」关闭当前 SDK 操作的项目通道，并等待执行进程结束。已写入的文件不会回滚，已提交到服务器的计算任务也不会自动取消；到「服务器任务」核对或取消。归档可恢复，不删除历史。单会话事件记录达到 64 MiB 时停止追加并报错，需要新建会话；不要删改记录来掩盖未确定的结果。

配置导入／导出目前不迁移会话历史、项目数据或 SDK 上下文。备份会话必须同时保留私有控制状态与对应项目 HOME；不要把历史文件、Access 凭据、API Key 或个人路径提交到仓库。

## 回归检查

1. 未登录、错误 Origin、缺少 CSRF 的写入必须拒绝。运行前验证当前 runtime digest、受控出口与 API 配置。
2. 创建、重命名、按项目筛选、归档和恢复；正文与工具输出必须作为文本显示，不能执行返回的 HTML。
3. 用获准的 API 做小型 Write／Read 任务和 `compute_health`，确认工具卡片与实际文件。单独确认计算提交权限，不为了界面检查创建付费资源。
4. 同一请求 ID 重试不得新增轮次。运行中刷新／断开页面后重连，原任务继续，历史不重复。
5. 第一轮提供一次性短语，控制端空闲重启并重新验证后，第二轮不重述短语，让模型直接回忆；确认 SDK session ID 连续且没有靠读文件补足上下文。
6. 对专用测试会话在 SDK 结果产生前点停止，确认该 SDK 进程结束、项目执行租约释放，其他项目和服务器 worker 不受影响。若测试等待命令被工具拒绝，另测运行中的 SDK 取消，不把拒绝当成停止成功。
7. 分别测试本机入口和实际 Access 公网入口；检查窄屏布局、可操作的输入框、工具展开与无前端异常。公网源站检查不替代实际浏览器登录与页面验收。

8. 使用合成附件检查批量选择／拖入、图片粘贴、上传中禁止发送、失败重试、刷新保留、切换会话目的不变、移除引用、同名不覆盖和重复发送去重。用真实 SDK Read 核对内容，不能把上传 HTTP 成功等同于模型读取成功。
9. 通过真实 WebSearch 获取来源；调用网页读取 MCP 并核对实际 fetch 结果和额外 API usage。私有 URL 和不可访问页面应明确失败。记录网页原生拖放、自动化事件处理测试和文件选择器验证各自覆盖范围。

上下文续接依据 [Agent SDK Sessions](https://code.claude.com/docs/en/agent-sdk/sessions)；消息输出粒度依据 [Streaming output](https://code.claude.com/docs/en/agent-sdk/streaming-output)。实测结果见 [验收记录](ACCEPTANCE.md)。
