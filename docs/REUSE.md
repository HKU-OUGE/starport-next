# 复用现有实现

优先提取已经验证的协议和行为，逐个适配，不整体复制现场工具目录。此仓库当前没有打包旧安装的私有状态、业务文件、凭据或服务名绑定。

| 来源 | 可复用部分 | 新仓库的变化 |
| --- | --- | --- |
| 现有 Mac 软路由管理 | 主备节点、端点别名、独立守卫、配置验证、事务回滚、上联变化重建 | 作为 Egress Adapter，接口不依赖具体网卡、固定地址或三节点数量 |
| 现有服务器自动同步 | 新鲜度、重连确认、CPU／内存／GPU 容量、运行时与代理验证 | 拆分观测字段，状态不随页面打开才刷新；纯判定函数先落地 |
| 现有隔离训练服务 | 每任务资源、只读依赖、日志游标、产物快照、分块传输与清理租约 | 作为 Compute Adapter；原任务与新会话的生命周期独立 |
| 现有网页控制台 | 后台缓存、增量读取、工具详情、附件／PDF／视频、幂等发送 | 与官方会话引擎事件适配，不依赖桌面解锁或 GUI 自动点击 |
| Starport Pi | 加密配置包、固定管理 RPC、私有存储、Node 原生控制端 | 保留 v1 包的解密兼容；配置／运行授权分离；完整 Agent 隔离 |
| Claude Agent SDK | 工具、上下文、权限、子代理、Skills、会话 | 在项目环境内运行，不回退到控制端执行工具 |
| CloudCLI | 网页和移动交互、文件树、会话／工具展示 | 接入单一会话所有者和 Access；不假设与 Desktop 原生会话可并发写入 |
| CC Switch | 供应商选择和 Desktop 第三方配置 | 可选导入／适配，不接管出口安全策略 |

## 提取顺序

1. 先迁移配置包和纯状态判定；无现场副作用，可以单独测试。
2. 在独立测试配置中接入一个现有网关，验证守卫与故障回滚。
3. 接入一个空闲测试工作区，复用已发布的依赖版本。
4. 接入官方引擎和网页事件；最后验证 Desktop SSH/SFTP。
5. 验收通过才加入生产服务注册，保留旧版本和明确回滚入口。

旧实现的成功记录只作为复用依据，不能替代新组合的端到端验收。任何上游代码迁入时保留原许可证和署名；不把私有部署路径或账号信息作为示例。
