# 网页会话交付检查

适用于用户选择 API 网页会话的 Windows／WSL2 安装。先读 [会话实现与限制](../../../docs/SESSIONS.md)。

- 使用已获准的 API 配置；官方账号登录不可用时，可以独立验收网页 API 会话，不重复要求用户登录原生客户端。
- 执行前核对当前边界验证、代理与模型网关；会话必须进入项目执行层，不能从 Windows 或 WSL 管理 shell 直接运行 SDK。
- 按文档的回归清单测试真实新建、输入、工具、历史、请求去重、停止、重启续接、归档恢复及实际公网入口。只测 API 不等于网页交互通过。
- 对话框优先使用页面内编辑。检查新建／发送回执丢失时保持原请求 ID；结果不明不得自动生成新 ID 重发。重启前先确认没有用户执行中的会话或未保存图形任务。
- 停止 SDK 不撤销已经提交的计算任务；核对任务面板后再报告。保留既有 worker、快捷方式、WSLg／网页桌面入口。
- 隐私记录保存在安装状态和项目目录，不提交源码。记录脱敏的通过项、真实费用、未测项和来源版本；不把 API 验收写成官方账号对话验收。

## 附件与联网验收

- 更新空闲运行时并重验边界；网页刷新加载新版本。不要为网页读取开放任意 CONNECT、直连 DNS 或宿主文件访问。
- 在专用测试会话中拖入／选择无个人信息的文字文件、粘贴合成 PNG，确认上传状态、刷新保留、移除引用和消息中的附件。实际调用 Read，核对文件内容和图形。重试保持上传 ID，重复发送保持消息 ID。
- 单文件 64 MiB、每条 8 个／128 MiB。文件夹走项目文件窗口。完整批次绑定原会话；切换项目不重定向上传。不要把 WSLg 跨系统拖放限制套用到网页上传。
- 真实调用 SDK WebSearch 和 `mcp__starport-web__web_fetch`；后者通过既有项目网关使用 Anthropic 服务端工具。核对来源和实际工具结果，不把 HTTP 200 或模型声称成功当作 fetch 成功。提供方不可用时应报告，禁止宿主网络回退。
- 当前 Opus 不接受强制 `tool_choice: tool/any`；保留自动工具选择，并检查是否真的产生 web_fetch 结果。失败不可伪装为已读取。
- 网页读取单独产生 API usage，不含在 SDK 的费用估算里。不要把实际新增用量记作零，也不要据此重新添加用户已移除的美元上限。
- 分别记录本机／Access、桌面／窄屏、真实系统拖入／自动化 drop 处理测试。浏览器扩展权限不足时不得声称真实系统拖入已验收，也不要为测试扩大扩展的文件访问权限。
