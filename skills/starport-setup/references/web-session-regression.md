# 网页会话交付检查

适用于用户选择 API 网页会话的 Windows／WSL2 安装。先读 [会话实现与限制](../../../docs/SESSIONS.md)。

- 使用已获准的 API 配置；官方账号登录不可用时，可以独立验收网页 API 会话，不重复要求用户登录原生客户端。
- 执行前核对当前边界验证、代理与模型网关；会话必须进入项目执行层，不能从 Windows 或 WSL 管理 shell 直接运行 SDK。
- 按文档的七项清单测试真实新建、输入、工具、历史、请求去重、停止、重启续接、归档恢复及实际公网入口。只测 API 不等于网页交互通过。
- 对话框优先使用页面内编辑。检查新建／发送回执丢失时保持原请求 ID；结果不明不得自动生成新 ID 重发。重启前先确认没有用户执行中的会话或未保存图形任务。
- 停止 SDK 不撤销已经提交的计算任务；核对任务面板后再报告。保留既有 worker、快捷方式、WSLg／网页桌面入口。
- 隐私记录保存在安装状态和项目目录，不提交源码。记录脱敏的通过项、真实费用、未测项和来源版本；不把 API 验收写成官方账号对话验收。
