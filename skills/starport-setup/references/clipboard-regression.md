# Windows 图片与文件回归

适用于已经明确启用 WSLg 的安装。参见[图片与文件](../../../docs/CLIPBOARD-FILES.md)。

1. 记录源代码版本、运行包摘要与 WSLg 版本，核对活动工作。只关闭获准的图形会话；保留计算任务。通过受控客户端安装入口补齐 `python3-gi`、`gir1.2-gtk-3.0`，空闲时迁移运行包、重启本安装控制端并重新验证边界。
2. 创建无个人内容的 PNG 和文本文件，保存尺寸、像素摘要与文件 SHA-256。从交付入口打开 WSLg 浏览器和文件管理器，默认 X11 与可选 Wayland 分别记录结果。
3. 在 Windows 画图或其他真实应用复制测试图片，用实际 Ctrl+V 粘贴到 WSLg 浏览器可接收图片的区域；核对 `image/png`、非空文件、尺寸和像素。只看到进程、桥接成功计数、`text/plain` 或 DOM 伪造事件都不算通过。浏览器工具的虚拟剪贴板不可替代系统剪贴板。
4. 反向从 WSLg 复制图片，在 Windows 应用粘贴；再做一次文字复制和第二张图片，检查旧图片不会覆盖新文字、重复图片不形成循环。图片本身不进入服务日志或状态接口。
5. 从项目文件管理器拖到同一项目应用，再从「Windows 文件窗口」把测试文件拖到 Windows 应用／测试目录，核对接收文件摘要。两个方向分别记录；不要把项目内成功表述为 WSLg 跨系统直接拖放成功。
6. 最后一个 WSLg 会话退出后，确认 `windowsImageClipboard.phase` 为 `stopped` 且监听器退出；网页桌面不启动它。检查网页桌面首帧和输入、关闭后切回 WSLg。会话切换需要用户保存工作；密钥环密码仍由用户输入。
7. 运行剪贴板传输／边界测试、相关图形与管道回归及源码检查。收据分别列出实际通过、用户报告、工具受限和待验项；公开收据只写合成数据与通用环境，真实路径和身份留本机。
